1. ¿Qué es Docker Compose?

Docker Compose permite definir y ejecutar aplicaciones que utilizan uno o varios contenedores mediante un archivo YAML.

Por ejemplo, puedes ejecutar una aplicación con:

  • Un contenedor para el backend.
  • Otro contenedor para una base de datos.
  • Un tercero para el frontend.

En lugar de iniciar cada contenedor manualmente, defines el entorno en un archivo y lo administras con unos pocos comandos.

2. Requisitos previos

  • Instalar Docker Desktop en Windows o macOS, o Docker Engine y el complemento Docker Compose en Linux.
  • Comprobar que Docker está funcionando.
  • Conocer los comandos básicos de una terminal.
docker --version
docker compose version
docker run hello-world

Si el último comando termina correctamente, Docker puede ejecutar un contenedor de prueba.

3. Entender el archivo compose.yaml

El archivo compose.yaml describe los servicios de la aplicación, sus puertos, sus volúmenes y sus configuraciones. 

services:
  web:
    image: nginx:alpine
    ports:
      - "8080:80"
  • services: define los servicios de la aplicación.
  • web: nombre del servicio.
  • image: imagen que utilizará Docker.
  • ports: conecta el puerto 8080 del equipo con el puerto 80 del contenedor.

YAML utiliza la indentación para organizar los datos. Usa espacios, no tabuladores.

4. Crear tu primer proyecto

Crea una carpeta llamada mi-proyecto y dentro un archivo llamado compose.yaml.

services:
  web:
    image: nginx:alpine
    ports:
      - "8080:80"
    restart: unless-stopped

Iniciar la aplicación

docker compose up -d

Probarla

Abre esta dirección en tu navegador:

http://localhost:8080

Detenerla

docker compose down

5. Comandos esenciales

# Iniciar los servicios
docker compose up -d

# Ver los servicios y su estado
docker compose ps

# Consultar los registros
docker compose logs

# Seguir los registros en tiempo real
docker compose logs -f

# Consultar los registros de un servicio
docker compose logs -f web

# Reiniciar los servicios
docker compose restart

# Detener y eliminar los contenedores y la red del proyecto
docker compose down

# Reconstruir imágenes y arrancar
docker compose up -d --build

Ejecuta estos comandos desde la carpeta donde está tu archivo compose.yaml.

6. ¿Qué son los volúmenes?

Los volúmenes permiten conservar datos aunque se eliminen los contenedores. Son especialmente importantes para bases de datos. 

services:
  db:
    image: postgres:17
    environment:
      POSTGRES_USER: app
      POSTGRES_PASSWORD: cambiar_esta_clave
      POSTGRES_DB: ejemplo
    volumes:
      - datos_postgres:/var/lib/postgresql/data

volumes:
  datos_postgres:

Este ejemplo es educativo. Para un entorno real, utiliza credenciales seguras y evita guardar contraseñas directamente en el archivo.

Ten cuidado: docker compose down -v también puede eliminar los volúmenes del proyecto y los datos que contienen.

7. Redes y comunicación entre servicios

Compose crea una red para el proyecto. Los servicios pueden comunicarse utilizando sus nombres como nombres de host. 

services:
  app:
    image: nginx:alpine
    ports:
      - "8080:80"
    depends_on:
      - db

  db:
    image: postgres:17
    environment:
      POSTGRES_USER: app
      POSTGRES_PASSWORD: cambiar_esta_clave
      POSTGRES_DB: ejemplo

En una aplicación que se conecta a PostgreSQL, el host de la base de datos sería db, no localhost.

depends_on establece el orden de inicio, pero no garantiza por sí solo que la base de datos ya esté lista para aceptar conexiones.

8. Errores comunes y soluciones

El puerto ya está ocupado

Prueba otro puerto del equipo:

ports:
  - "8081:80"

El contenedor se detiene

docker compose ps
docker compose logs

Los cambios no aparecen

Si modificaste el código de una imagen propia, reconstruye:

docker compose up -d --build

No encuentra el archivo Compose

Comprueba que estás en la carpeta correcta y que el archivo se llama compose.yaml o docker-compose.yml.

9. Práctica final

Comprueba lo que has aprendido:

  1. Crea un archivo compose.yaml con un servicio Nginx.
  2. Expón el puerto 8080.
  3. Inicia el servicio en segundo plano.
  4. Abre el navegador y visita localhost:8080.
  5. Consulta los registros del contenedor.
  6. Detén el proyecto sin eliminar volúmenes innecesariamente.

Comandos de repaso

docker compose up -d
docker compose ps
docker compose logs
docker compose down

Objetivo: comprender cómo definir, iniciar, inspeccionar y detener una aplicación con Docker Compose.
